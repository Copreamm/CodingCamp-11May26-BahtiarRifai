## ✨ Features

### Core

- 📝 **Add Transactions** — Log expenses with name, amount, and category
- 🗑️ **Delete Transactions** — Remove any entry instantly
- 💵 **Live Total Balance** — Updates automatically on every change
- 🥧 **Pie Chart** — Visual spending breakdown by category (powered by Chart.js)

### Bonus Challenges

- 🏷️ **Custom Categories** — Not just Food/Transport/Fun — add your own
- 📅 **Monthly Summary** — Filter and review spending by month
- 🔀 **Sort Transactions** — By newest, oldest, highest, or lowest amount
- 🌙 **Dark / Light Mode** — Toggle anytime, preference is saved
- 💾 **Persistent Storage** — Everything saved in your browser via LocalStorage

## 🛠️ Tech Stack

## 📋 How to Use

1. **Add a transaction** — Fill in the item name, amount, and pick a category
2. **Use a custom category** — Type in the "Custom Category" field to create your own
3. **View your chart** — The pie chart updates live as you add/remove items
4. **Filter by month** — Use the monthly summary dropdown to view a specific period
5. **Sort your list** — Use the sort dropdown to reorder transactions
6. **Switch themes** — Click the 🌙 button at the top right
